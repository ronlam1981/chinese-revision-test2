# 初二語文｜第一段測驗二

繁體中文溫習網站，支援手機、平板與電腦。

範圍包括四篇課文、參考默寫、名句37–45、近義成語45–48、重點成語80–88、修辭、文學與澳門文化、文言閱讀及材料分析。

共102道獨立練習：60道選擇、42道自評。每輪分章練習最多10題，選擇小測最多40題，不重複填充。簡答依要點自評，不作AI自動評分。

古文默寫為有來源的參考版本，分段、異體字及標點須與課堂版本核對。練習為原創，並非校方試題；材料案例清楚標為模擬。現代課文只提供原創摘要，不重製全文。
